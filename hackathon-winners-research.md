## PATTERNS & ANALYSIS

### What Types of Projects Consistently Win Hackathons?

**1. "Solve Your Own Problem" Projects**
The biggest pattern across ALL hackathons: winners solve problems they personally experience.
- CrossBeam: Attorney frustrated by California permitting
- postvisit.ai: Cardiologist frustrated by patient confusion
- VitalLink: Personal health data frustration
- Camfer: Engineers needing iterative design tools
- Guardian: Healthcare workers dealing with A&E triage

**2. AI Agents / Multi-Agent Systems**
The dominant theme across 2024-2026 hackathons:
- Multi-agent debate (Anthropic PRD tool)
- Supply chain agents (RiskWise)
- Browser agents (Browser Use, Kernel)
- Research agents (Apollo Deep Research)
- Incident management agents (WorkWizee)

**3. Healthcare / Accessibility**
Consistently overrepresented among winners:
- Gaze Link (ALS communication via eye tracking)
- Vite Vere (cognitive disability assistance)
- Guardian (A&E triage)
- postvisit.ai (patient health guidance)
- Emergency Triage Automation
- MedClarify (medical jargon translation)

**4. Developer Tools / Infrastructure**
Always present, especially at larger hackathons:
- KeyHaven (API key management)
- SmoothMQ (SQS replacement)
- InstantDB (Firebase alternative)
- PGlite (In-browser Postgres)

**5. Creative/Fun Projects (for viral potential, not necessarily winning)**
- Tetris in a PDF
- Clippy for LLMs
- Outdraw (drawing game vs AI)
- BananaBets (predict hackathon winners)

### What Makes Something Go VIRAL vs Just Winning?

| Factor | Wins Hackathons | Goes Viral | Both |
|--------|----------------|-----------|------|
| Solves real problem | Yes | Sometimes | Yes, if the problem is universal |
| Technical complexity | Yes | No | Rarely |
| Emotional story | Sometimes | Yes | Yes (built for my daughter, built after layoff) |
| Visual/demo-able | Helps | Critical | Yes |
| Novelty/surprise | Helps | Critical | Yes (OpenClaw negotiating car prices) |
| Nostalgia | No | Yes | Clippy, Windows XP portfolio |
| Hardware/physical | Sometimes | Yes | Open-source laptop, synth for daughter |
| Open source | Sometimes | Yes | Postiz, OpenClaw, OpenAlternative |
| Counter-intuitive | Sometimes | Yes | Lawyer beats 500 devs, 18yo wins YC |
| Speed to value | Yes | Yes | 5-minute app creation, 4-minute video editing |

### Common Winning Categories (Ranked by Frequency)

1. **AI Agents & Automation** - Dominant 2024-2026 theme
2. **Healthcare & Medical AI** - Always wins sympathy + impact points
3. **Developer Tools & Infrastructure** - Reliable winner category
4. **Education & Learning** - Especially AI tutors, visual learning
5. **Accessibility** - Eye tracking, cognitive support, translation
6. **Gaming / GameFi** - Especially at ETHGlobal
7. **Financial / FinTech** - Supply chain, trading, planning
8. **Creative Tools** - Video editing, music, design
9. **Privacy / Local-first** - Growing trend: local LLMs, FOSS alternatives
10. **Physical/Hardware + AI** - Robotic arms, smart displays, IoT

### The "Viral Formula" for Developer Community

Based on 2024-2025 data, projects that both win AND go viral tend to have:

1. **A demo that fits in a tweet** - 30-second video, screenshot, or one-liner
2. **A surprising protagonist** - Non-developer builds something amazing, teenager wins, etc.
3. **Immediate utility** - People can use it RIGHT NOW
4. **Open source** - GitHub stars compound virality
5. **Timing** - Launch when the conversation is already happening (e.g., vibe coding during the Karpathy wave)

### The Shift: Domain Experts > Developers

The most significant pattern emerging in 2025-2026:
- Anthropic Opus 4.6 hackathon: Won by a lawyer, a father, and a cardiologist
- 13,000 applicants, 500 developers, and the top prizes went to people who never shipped software
- The valuable skill is **deep domain knowledge of a real problem**, not coding ability
- Vibe coding tools (Cursor, Bolt, Lovable, Replit Agent, Claude Code) have made this possible
